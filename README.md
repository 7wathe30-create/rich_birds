# Rich Birds — Voxel World 04

Утверждённый воксельный игровой дизайн внедрён в интерактивный прототип. **Это не Web3 MVP:** все активы, владельцы и передачи — локальные демо-данные. Подписи, кошелёк, контракты и платежи не подключены.

## Запуск и проверки

```sh
npm ci
npm run dev
npm run build
npm test
npm run avatars:generate
```

Managed Preview: `.hoplite/settings.json`, порт 3000. Генерация аватаров воспроизводима; все 15 SVG хранятся в `public/avatars/` и входят в production-сборку.

## Рабочие сценарии

1. Карта без регистрации: 100 000 постоянных номеров, поиск по номеру/X,Y, фильтры, колесо и +/−, перемещение мышью/касанием, клавиатурные стрелки и Enter.
2. «Профиль»: обязательные ник и аватар. 15 оригинальных воксельных персонажей либо свой PNG/JPEG/WebP до 2 МБ. Загрузка декодируется, обрезается по центру и перекодируется в PNG 256×256; SVG и некорректные форматы отклоняются. Никакой отправки изображения на сервер.
3. На свободном участке «Примерить участок · демо» → явное предупреждение → добавление в «Мои земли». На карте и в панели появляется выбранный аватар и ник. Это не покупка или mint NFT.
4. Изменение профиля обновляет аватары на всех своих демо-землях. Состояние сохраняется в `localStorage` после перезагрузки и синхронизируется через событие `storage` между вкладками. При ошибке записи UI не сообщает об успешном сохранении.
5. Владелец демо-земли может размещать/убирать четыре демонстрационные птицы. Гостю доступны только просмотр и отсутствие управляющих кнопок.
6. «Проверить смену владельца · демо» показывает отдельное подтверждение. У земли меняются владелец и аватар, прежний владелец теряет управление, размещения удаляются, птицы остаются в демо-инвентаре. Возврат земли в модели не восстанавливает старые размещения.

## Структура

- `src/design.jsx` — игровая оболочка, земля, коллекция и демонстрационные сценарии.
- `src/voxel.css` — утверждённый угловатый HUD поверх базовой адаптивной компоновки `design.css`.
- `src/profile-editor.jsx` — редактирование профиля и безопасная нормализация изображения на клиенте.
- `src/avatars.js`, `scripts/generate-avatars.mjs`, `public/avatars/` — каталог и исходник 15 оригинальных портретов.
- `src/demo-state.js` — чистая модель профиля, демо-владения, передач и размещения птиц. Не использовать как серверную авторизацию.
- `src/atlas-map.js` — Canvas, только видимые клетки; перерисовка по событиям. Статус каждой клетки соответствует демо-модели: зелёный — свободно, красный — занято, золотой — продаётся.
- `src/world.js` — `tokenId = Y × 400 + X + 1`, X 0–399, Y 0–249. Непериодические, воспроизводимые демо-статусы; плотность и счётчик не являются игровыми параметрами или данными блокчейна.
- `tests/` — все номера, поиск/границы, масштаб, аватары, обязательность профиля, сохранение, потеря доступа, перенос птиц, очистка размещений и повреждённое хранилище.

Исторический светлый прототип в `main.jsx`, `scene.jsx`, `canvas-renderer.js`, `style.css` не импортируется текущей точкой входа. Текущий курятник — интерактивная иллюстративная сцена, не полноценный новый 3D-релиз.
