# Rich Birds на своём компьютере

## Windows

1. Откройте [обновлённую версию проекта](https://github.com/7wathe30-create/rich_birds/tree/hoplite/histiaia-oreos-47b0a367--wallet-db), нажмите **Code → Download ZIP** и распакуйте архив. Не запускайте файлы прямо внутри ZIP.
2. Установите актуальный **Node.js 22 LTS (22.13 или новее)** с https://nodejs.org/ .
3. Откройте распакованную папку и дважды нажмите **`ЗАПУСК-НА-WINDOWS.bat`**. Он установит зависимости, запустит сервер, интерфейс и БД.
4. Дождитесь надписи **Rich Birds listening**, затем откройте **http://localhost:3000** в браузере. Если сервер пишет ошибку, не закрывайте окно: скопируйте её текст.
5. Для кошелька установите доверенное EVM-расширение с официального сайта его разработчика (например, MetaMask). На сайте нажмите **«Подключить кошелёк»**, разрешите подключение и переключение в **Robinhood Chain Testnet**. Затем отдельно подпишите сообщение входа и создайте профиль.

**Seed-фразу нигде на сайте вводить не нужно. Подпись входа не переводит средства.** Транзакции покупки пока не включены.

Чёрное окно нужно оставить открытым. Остановить — `Ctrl+C`. База профилей сохраняется в `data/rich-birds.sqlite` внутри папки проекта. При скачивании обновления сохраните свою папку `data`, если хотите сохранить профили.

## Через терминал (Windows/macOS/Linux)

```sh
git clone --branch hoplite/histiaia-oreos-47b0a367--wallet-db https://github.com/7wathe30-create/rich_birds.git
cd rich_birds
npm ci
npm start
```

В PowerShell, если заблокирован `npm.ps1`, используйте `npm.cmd ci` и `npm.cmd start` — менять глобальные политики безопасности не требуется.

На macOS/Linux из папки проекта также работает `sh start-local.sh`. После установки зависимостей откройте `http://localhost:3000`.

## Настройки и ошибки

- Если порт занят, завершите старый сервер `Ctrl+C`. Сервер не переключается незаметно на другой порт: адрес важен для подписываемого сообщения входа.
- Для другого порта задайте одновременно `PORT` и `APP_ORIGIN`, например `PORT=3001`, `APP_ORIGIN=http://localhost:3001` в `.env` (скопируйте `.env.example`). Открывайте сайт по адресу из `APP_ORIGIN`.
- «Кошелёк не найден» — откройте сайт в браузере с установленным EVM-расширением. Мобильный WalletConnect ещё не добавлен.
- Не удаётся подпись — проверьте выбранный адрес/сеть в расширении и используйте «Войти» заново. Никто не должен просить вас прислать приватный ключ.
- «Продажи не открыты» — это не ошибка локального запуска: NFT-контракты, платёжная валюта и покупки пока не подключены.
- Не публикуйте `.env` и папку `data`: там могут быть приватные адреса RPC, профили и серверные сессии.
